# docs/ — Documentation

- [`formulas_and_understanding.md`](formulas_and_understanding.md) — key formulas and intuition
  behind the detection/demodulation/framing pipeline (energy detection, FSK bit decision, sync
  correlation, address extraction, latency, Pd/Pfa/miss-rate definitions).
- [`system_design.md`](system_design.md) and [`fpga_architecture.md`](fpga_architecture.md) —
  early (v0) algorithmic and architectural design notes, written before the multi-channel
  implementation existed. Each now carries a note pointing to the as-built architecture, which
  differs in a few respects (no event FIFO / AXI-Lite / interrupt interface, no per-event
  timestamp fields, `N_channel` defaults to 2 rather than 1) — see the top-level
  [`README.md`](../README.md) and the project book for the current design.
- `figures/` — block diagrams used in the project book (`fig1_system_architecture.png`,
  `fig2_pipeline.png`, `fig3_output_word.png`), generated by `figures/make_figures.py`.
- `preview/` — page previews of the project book PDF.
- `generate_project_book.py` — generates the Hebrew final-project book
  (`Project_Book_FSK_Multichannel.docx`) from the project's design and results.

For the authoritative, up-to-date description of the system, see the top-level
[`README.md`](../README.md) and
[`Project_Book_FSK_Multichannel.pdf`](../Project_Book_FSK_Multichannel.pdf).
